# 진수 변환 게임

2진수 · 8진수 · 10진수 · 16진수 바꾸기를 60초 동안 겨루는 8비트 스타일 브라우저 게임입니다.

- 스테이지 6개: 비트 카드, 2진수 ▶ 10진수, 10진수 ▶ 8·16진수, 2진수 끊어 읽기, 색 코드, 비밀 메시지
- 맞힐수록 레벨이 오르고, 연속 정답 콤보 보너스와 힌트(−3점)가 있어요
- 틀린 문제는 풀이와 함께 오답 노트로 정리
- 이름별 최고 점수와 순위표는 그 기기의 브라우저에 저장
- **이지 모드**: 처음 화면에서 고르거나 `easy.html`로 바로 열기. 스테이지 1·2만, 2진수 6자리(0~63)까지만 나오고 기록은 따로 저장

바로 하기: https://jewonr.github.io/jinsu-game/

이지 모드 바로 하기: https://jewonr.github.io/jinsu-game/easy.html

외부 의존성 없는 단일 HTML 파일이라 `진수변환게임.html`을 브라우저로 열기만 해도 인터넷 없이 동작합니다.
